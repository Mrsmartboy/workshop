# Codegnan Workshops & LMS Platform

Modern interactive learning management and workshop portal built with Next.js 14, React, Tailwind CSS, and Lucide Icons.

## Features
- **Hands-on Workshops, Hackathons & Bootcamps**: Interactive programs catalog with autoplay previews.
- **Dedicated Media Gallery**: Fullscreen lightbox player with filter categories and live search.
- **Upcoming Flagship Events**: Detailed event cards for Data & AI, AI Coding Agents, and Claude Mastery Cohorts.
- **Responsive Design**: Designed with modern UI/UX principles and smooth keyframe micro-animations.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the application.
